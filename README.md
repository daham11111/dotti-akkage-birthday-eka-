# Look Up – GitHub Pages site

## Upload karana widiya (How to upload)
1. GitHub eke aluth **public** repository ekak hadanna.
2. **Add file → Upload files** click karala, me folder eke thiyena **okkoma files saha folders** (index.html, content.json, assets, media, .nojekyll) drag karala danna → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, folder **/(root)** → **Save**.
4. Minithu 1-2 kin link eka enawa: `https://<username>.github.io/<repo-name>/`

## ✏️ Edit button eken edit karana widiya (lesima kramaya)
1. Site link eka open karala dakunu yata **✏️ Edit** click karanna (nathnam `.../edit.html`).
2. Photos, song, video **Upload** karala, text wenas karanna.
3. **📦 Download updated ZIP** click karanna → unzip karanna.
4. GitHub repo eke **Add file → Upload files** walin okkoma files danna → **Commit changes**.
5. Minithu 1-2 kin link eka thiyena hamotama aluth ewa penawa.

## Photos / MP3 add karana widiya (GitHub eken kelinma)
`media` folder ekata me namwalin files upload karanna (GitHub → media folder ekata yanna → Add file → Upload files):

| File name | Thena |
|---|---|
| photo1.jpg … photo4.jpg | Scrapbook photos 4 |
| window1.jpg … window4.jpg | Plane window photos 4 |
| place1.jpg … place4.jpg | Map eke pins 4 |
| song.mp3 | Music player eka |
| intro.mp4 | Mulinma pennana video eka (danatamath thiyenawa) |

Wena nam use karanna one nam, `content.json` eka GitHub eke open karala ✏️ (Edit) click karala nam wenas karanna.
Letter eka, titles, captions, map names okkoma `content.json` eke wenas karanna puluwan.

Note: File nama case-sensitive (Photo1.JPG ≠ photo1.jpg). GitHub eke ek file ekak 25MB walata adui wenna one (browser upload).
